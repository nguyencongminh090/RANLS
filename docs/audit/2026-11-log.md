## 2026-11-12 — UX-09: Settings Apply with an invalid engine path (option a)

**Status:** Active

- **Prompt:** UX-09 (from the I18N-06 visual pass) needed a design call: with an invalid engine path,
  Apply is disabled on every tab, so a first-run user cannot change Language/Theme.
- **Decision (user):** option (a). Apply is always sensitive. While the path is invalid, Apply applies
  and persists every other setting and keeps the previously saved `enginePath` (invalid text is
  discarded, no engine reload). A tooltip on Apply says the engine path will not be saved.
- **Rejected:** (b) keep blocking + explain on every tab — still blocks a core non-engine setting;
  leave as is — hides the language setting from users without an engine.
- **Unchanged:** the engine-launch guards (`EngineController` empty-path return, spawn failure
  reporting) and the settings file format.
- **Knowledge:** UX heuristics (user control and freedom, visibility of system status, error
  prevention) — `docs/knowledge/`; `gtk-ui-design` skill.
