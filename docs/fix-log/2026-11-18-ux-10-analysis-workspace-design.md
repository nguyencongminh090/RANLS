Sprint 28 task UX-10: review the main window with the engine off in a new game and mid-game with live analysis and a branched tree, then deliver two annotated mockups on one layout, the Visual and Table views for one selection, a narrow-window and panel-restore annotation, and a brief interaction spec. ## Root cause

Not a bug fix. This entry records a design deliverable, so there is no root cause. The review found these gaps in the current window: start-engine and analyze controls are not distinguishable (icon-only), the chip states differ only by dot color, a failed start leaves the chip at OFF with the error only in the Engine Log, the selected node and branches are weakly marked in Visual, the Table's current row can sit below the fold, and the log pane costs 208 px of height while the panel toggles are 3 clicks deep. Details in the spec.
